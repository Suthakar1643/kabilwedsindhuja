# 💍 Arun & Priya — Digital Wedding Invitation

A royal, modern, and interactive digital wedding invitation web app designed for easy sharing over WhatsApp and zero-cost hosting on **GitHub Pages**.

---

## 🌟 Key Features
1. **🌸 Falling Flower Petals & Gold Sparkles**: Interactive HTML5 canvas animation with marigolds and rose petals.
2. **🎵 Auspicious Carnatic Melody**: Built-in soothing flute/veena Raga Mohanam instrumental synthesizer (plays directly in browser with zero dependencies!).
3. **🌐 Bilingual (தமிழ் & English)**: 1-click instant language switcher for elders and youth.
4. **⏳ Live Muhurtham Countdown**: Dynamic days, hours, minutes, and seconds countdown to the auspicious ceremony.
5. **📍 1-Click Google Maps Navigation**: Direct link to the wedding mandapam with coordinates.
6. **📅 Add to Calendar (.ics download)**: Direct calendar reminder support for Apple Calendar, Google Calendar, and Outlook.
7. **💌 WhatsApp RSVP & Live Wishes Wall**: Guests can submit their attendance and post their blessings, which automatically prepares a formatted WhatsApp confirmation!
8. **👑 Personalized Guest Links**: Generates links like `your-site.github.io?guest=Karthik+Family` to display a royal personal welcome banner.

## 🚀 How to Host for FREE on GitHub Pages (Step-by-Step)

Since this website is built with pure HTML5, CSS3, and JavaScript, **no build process is required**. It runs directly out of the box!

### Method 1: Upload directly via GitHub Website (No command line needed!)
1. Go to [github.com](https://github.com) and log into your account.
2. Click **"New"** (or the green button) to create a new repository.
3. Name it (for example: `wedding-invite` or `arun-priya-wedding`).
4. Set it to **Public**, and click **"Create repository"**.
5. On the next screen, click **"uploading an existing file"**.
6. Drag and drop all the files and folders from this folder:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `assets/` (containing `couple.jpg` and `mandapam.jpg`)
7. Click **"Commit changes"**.
8. Go to **Settings ➔ Pages** (on the left sidebar of your repository).
9. Under **"Build and deployment" > Branch**, select `main` and `/ (root)`, then click **Save**.
10. Wait 1 minute and refresh the page. Your free live link will be shown at the top:
    👉 `https://your-username.github.io/wedding-invite/`
